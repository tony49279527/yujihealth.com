# Do not place source evidence here

This website repository may be deployed as public static content. Do not place certificate originals, customer files, orders, signatures, QR codes, shipment records, personal data, or unredacted test/QC records in this directory.

Keep originals in a restricted external Drive or private controlled directory. Only an irreversibly redacted derivative with written approval for the exact public file may be added to the website outside this ignored inbox path and registered in `../evidence-manifest.csv`.
